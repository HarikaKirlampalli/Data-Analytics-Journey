# Flipkart E-Commerce Sales Analysis Dashboard

## 📌 Project Overview
This project is an interactive E-Commerce Sales Analysis Dashboard developed using Microsoft Power BI. It analyzes Flipkart sales data to understand sales performance, product categories, brand performance, monthly trends, customer ratings, and payment method contributions.

## 🎯 Project Objectives
- Analyze overall sales and order performance.
- Identify top-performing product categories and brands.
- Track monthly sales trends.
- Analyze monthly orders by product category.
- Understand payment method-wise sales contributions.
- Monitor overall sales target achievement.
- Explore data using interactive slicers.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX (Data Analysis Expressions)

## 📊 Key Performance Indicators (KPIs)
- Total Sales: 293.13M
- Total Orders: 10K
- Product Count: 1.199K
- Average Product Rating: 3.87

## 📈 Dashboard Visualizations

1. **Sales by Category:** Compares sales across different product categories.
2. **Monthly Sales Trend:** Shows monthly sales performance using a Line Chart.
3. **Sales by Brand:** Identifies and compares brand-wise sales performance.
4. **Monthly Orders by Product Category:** Analyzes monthly order distribution across product categories.
5. **Overall Sales Target Achievement:** Displays sales performance against the target using a Gauge Chart.
6. **Payment Method-wise Sales Contribution:** Shows sales distribution across different payment methods using a Treemap.

## 🎛️ Interactive Filters
- Category
- Customer State
- Order Status

## 🔍 Key Insights
- Electronics is the highest-selling product category in the dashboard.
- Dell, Sony, and JBL are among the leading brands displayed.
- Monthly sales fluctuate throughout the year.
- UPI contributes a significant share of payment method-wise sales.
- The dashboard provides an overview of sales performance and customer purchasing patterns.

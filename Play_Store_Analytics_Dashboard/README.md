# 📱 Google Play Store Apps Analysis – Power BI

## 📌 Project Overview
The Google Play Store Apps Analysis project is an interactive Power BI dashboard designed to analyze app performance, category distribution, ratings, installs, pricing, and update trends.

The project uses a cleaned Google Play Store dataset to generate meaningful insights and support data-driven business decisions.

## 🎯 Project Objectives
- Analyze application distribution across categories.
- Compare average ratings across categories.
- Understand Free vs Paid app performance.
- Analyze estimated installs and app reviews.
- Identify high-performing app categories.
- Examine paid app percentages.
- Analyze app size and yearly update trends.
- Understand category-wise install contribution.

## 🛠️ Tools & Technologies

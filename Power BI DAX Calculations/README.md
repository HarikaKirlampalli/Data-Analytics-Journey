# Power BI DAX Calculations & Data Visualization

## 📌 Project Overview
This project focuses on learning and implementing **DAX (Data Analysis Expressions)** in Microsoft Power BI to perform data calculations and create meaningful visualizations.

The project uses sales and order-related data to calculate important business metrics and present insights through interactive charts and KPI cards.

## 🎯 Project Objectives
- Understand and implement DAX calculations in Power BI.
- Calculate total sales, profit, quantity, and discounts.
- Analyze average, maximum, and minimum values.
- Create meaningful charts to visualize business performance.
- Understand how DAX measures work with different categories and filters.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Analysis

## 📊 DAX Calculations Implemented

A total of 15 DAX measures were created:

| Category | DAX Measures |
|---|---|
| Sales | Sum of Sales, Average Sales per Order, Max Sales, Min Sales |
| Profit | Total Profit, Average Profit, Highest Profit, Least Profit |
| Quantity | Total Quantity Sold, Average Quantity |
| Discount | Total Discount, Average Discount |
| Orders | Total Number of Orders |
| Shipping Cost | Total Shipping Cost, Average Shipping Cost |

## 📈 Visualizations Created

The project includes the following visualizations:

1. **Clustered Column Chart** – Total Sales and Total Profit by Product Category.
2. **Bar Chart** – Average Sales and Profit by Region.
3. **KPI Cards** – Total Profit, Total Orders, Total Quantity Sold, and Total Sales.
4. **Donut Chart** – Total Sales by Customer Segment.
5. **Line Chart** – Total Sales, Profit, and Quantity Sold.

## 💡 Key Learning Outcomes
- Understanding DAX functions such as SUMX, AVERAGEX, MAXX, MINX, SUM, AVERAGE, and CALCULATE.
- Creating calculated measures.
- Applying DAX measures in different visualizations.
- Understanding filter context and aggregation.
- Designing meaningful Power BI reports.
